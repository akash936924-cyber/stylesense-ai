# StyleSense AI 👗✨

AI-powered fashion search engine built with **Next.js, TypeScript, CLIP AI, and Supabase**. Upload outfit inspiration images, discover visually similar clothing, generate matching color palettes, and create personalized looks from multiple fashion stores.

---

## Features

* AI-powered image search using CLIP
* Color harmony recommendations
* Outfit inspiration from uploaded images
* Multi-store product search
* Budget-based filtering
* Styling Studio for creating outfits
* Wishlist & Saved Looks
* Responsive modern UI

---

## Getting Started

Clone the repository:

```bash
git clone https://github.com/akash936924-cyber/stylesense-ai.git
cd stylesense-ai
```

Install dependencies:

```bash
npm install
```

Create environment file:

```text
.env.example → .env.local
```

Run the development server:

```bash
npm run dev
```

Open **http://localhost:3000**
